Implementación de filtros digitales con OpenCV

Introducción

Este proyecto implementa filtros digitales utilizando OpenCV con una interfaz gráfica en WinForms. Permite cargar imágenes o usar la cámara para aplicar filtros en tiempo real.

Objetivo

Desarrollar una aplicación interactiva que permita aplicar filtros digitales y modificar parámetros mediante sliders.

Filtros disponibles

  • Escala de grises
  • Binarización
  • Canny
  • Sobel
  • Separación RGB
  • Rotación
  • Zoom

Conclusión

El proyecto combina teoría y práctica del procesamiento digital de imágenes usando OpenCV.
